# Instalação

```bash
pip install gender-guesser-br
```

As dependências são o [DadosAbertosBrasil](https://www.gustavofurtado.com/DadosAbertosBrasil/),
que acessa a API do IBGE, e o `requests`.

Requer Python 3.10 ou superior. Como os dados vêm da API do IBGE, as previsões precisam de acesso
à internet.
